# StepWise AI – Interactive Website Simulation

An interactive web-based simulation of a smart campus sustainability system that connects kinetic flooring, energy storage, smart waste bins, and AI-based analysis to demonstrate how everyday human movement can support more efficient waste management.

## Overview

StepWise AI is a website prototype designed to demonstrate how a campus-wide kinetic flooring and smart waste management system could work.

The concept begins with kinetic floor tiles that generate small amounts of electricity when people walk over them. The harvested energy is stored and used to support low-power smart-bin monitoring systems.

Smart bins monitor their waste levels using simulated ultrasonic sensor readings. The collected data is then displayed on the StepWise AI dashboard, where the system analyzes energy availability, pedestrian activity, bin fill levels, and estimated waste collection needs.

The website brings these components together in one interactive simulation, allowing users to explore how the different parts of the proposed system communicate and work together.

## Main Objectives

- Demonstrate how kinetic flooring can generate and store electrical energy from footsteps.
- Simulate how stored energy can support low-power smart-bin monitoring.
- Display waste-bin fill levels using simulated ultrasonic sensor readings.
- Demonstrate how sensor data can be transmitted to a central monitoring dashboard.
- Analyze pedestrian activity and waste demand to compare potential kinetic flooring locations.
- Generate waste collection recommendations based on bin fill levels and estimated time until full.
- Demonstrate how energy availability and waste management information can be considered together when making system decisions.

## Key Features

### 1. System Dashboard

The main dashboard provides an overview of the entire simulated system.

It displays:
- Total simulated footsteps.
- Energy generated by the kinetic flooring.
- Available stored energy.
- Number of smart bins requiring attention.

The dashboard updates when users interact with the simulation.

### 2. Kinetic Flooring Monitor

This section simulates electricity generation from footsteps.

Users can enter a number of footsteps and run the simulation to calculate the estimated energy generated.

The current simulation uses:
- 5 millijoules of raw energy per step.
- 70% energy conversion efficiency.

The website calculates the usable energy and adds it to the simulated energy storage system.

### 3. Energy Storage Monitor

This section demonstrates how harvested energy is stored and used by the system.

It displays:
- Current stored energy.
- Storage capacity.
- Storage percentage.
- Energy consumed by monitoring and data transmission.
- Excess energy that exceeds the available storage capacity.

The simulation also checks whether enough stored energy is available before allowing a smart bin to perform its simulated monitoring and transmission operation.

### 4. Smart Bin Monitoring

The website includes four example smart bins located in different campus areas:

| Smart Bin | Location | Initial Fill Level |
|---|---|---:|
| Bin 01 | Main Entrance | 32% |
| Bin 02 | Library | 68% |
| Bin 03 | Cafeteria | 88% |
| Bin 04 | Lecture Hall | 48% |

Users can select a bin, add simulated waste, and monitor how its fill level changes.

The website also demonstrates an ultrasonic sensor calculation. The sensor measures the distance between the top of the bin and the waste surface.

The estimated fill percentage is calculated using:

`Fill Level (%) = ((Bin Height - Sensor Distance) / Bin Height) × 100`

Users can run the **Measure and Transmit Data** function to simulate a sensor reading and data transmission operation. The website checks the available energy and updates the displayed readings and transmission status.

### 5. System Connectivity

This section visually represents the communication between the main system components:

1. Kinetic flooring generates electricity.
2. Energy is transferred to the storage system.
3. Stored energy supports smart-bin monitoring.
4. Smart-bin readings are transmitted wirelessly.
5. The website receives and displays the simulated data.

The connectivity indicators represent the proposed system connections. They do not currently establish communication with physical hardware.

### 6. AI-Based Analysis and Optimization

The AI analysis section demonstrates how the system could use collected information to support better campus sustainability decisions.

It includes:

**Energy Analysis**

Evaluates the available stored energy and determines whether the system has sufficient energy for simulated smart-bin monitoring and transmission.

**Kinetic Flooring Location Optimization**

Compares potential campus locations based on:
- Pedestrian activity.
- Nearby waste-bin demand.
- Estimated installation cost.

The website uses a weighted scoring method to compare the locations and identify which areas may be more suitable for kinetic flooring installation.

**System Optimization**

Evaluates the simulated system conditions, including energy availability and smart-bin status, to provide operational recommendations.

The current prototype uses predefined rules and weighted calculations to perform its analysis. It does not yet use a trained machine-learning model.

### 7. Waste Collection Recommendations

This section demonstrates how the system can help campus maintenance teams prioritize waste collection.

It considers:
- Current bin fill percentage.
- Estimated time until the bin becomes full.
- Collection priority.
- Recommended collection action.

The website uses predefined fill-level thresholds and assumed waste accumulation rates to generate recommendations.

For example, a bin with a high fill level may receive a higher collection priority than a bin that is only partially full.

The estimated time until full is calculated using:

`Time Until Full = ((100 - Current Fill Level) / Daily Fill Rate) × 24`

The result is an estimate based on simulated waste accumulation rates, not a prediction from live historical data.

## How the Simulation Works

The website demonstrates the proposed system through an interactive sequence:

**Step 1 – Generate Energy**

Enter a number of footsteps in the Kinetic Flooring Monitor. The website calculates the estimated usable energy generated.

**Step 2 – Store Energy**

The generated energy is added to the simulated storage system, up to its maximum capacity.

**Step 3 – Monitor Smart Bins**

Select a smart bin and add simulated waste to change its fill level.

**Step 4 – Measure and Transmit Data**

Run the sensor measurement function. The website calculates the estimated ultrasonic sensor distance and checks whether sufficient stored energy is available for the simulated operation.

**Step 5 – Analyze System Data**

Run the AI analysis to evaluate energy availability, compare potential flooring locations, and assess the current waste management conditions.

**Step 6 – Generate Collection Recommendations**

Update the collection recommendations to identify which bins require attention and which should be prioritized.

## Running the Website

The website does not require a backend server for its current simulation.

To run it locally:

1. Download or clone the project repository.
2. Open the project folder.
3. Locate `index.html`.
4. Open `index.html` in a web browser.
5. Navigate through the dashboard and interact with the simulation controls.

The website can also be hosted using GitHub Pages.

## Current Prototype Limitations

StepWise AI is currently a software-based simulation of a proposed physical system.

The following features are simulated rather than connected to actual hardware:

- Kinetic electricity generation.
- Energy storage and consumption.
- Ultrasonic smart-bin measurements.
- Wireless data transmission.
- Campus pedestrian activity data.
- AI-based analysis and optimization.
- Waste accumulation and collection predictions.

The prototype does not currently include physical kinetic floor tiles, actual ultrasonic sensors, ESP32 controllers, or a live wireless network connection.

Its calculations use predefined values and assumptions to demonstrate the intended system behavior. Actual hardware testing and real-world data would be required to validate the energy generation estimates and operational performance.
